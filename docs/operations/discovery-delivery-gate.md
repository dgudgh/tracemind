# 自动发现与拓扑交付门禁

核验日期：2026-10-26。适用于资产自动发现、成员身份、归属、复制关系、HA 判定及拓扑渲染的修改。

## 完成条件

历史漏验发生在模块之间：采集函数、身份函数及画线函数分别通过，真实发现数据却没有贯通。因此必须使用同一批数据跑完：

`采集字段 → 成员身份 → CMDB 持久化 → 规范资产 → API 回读 → 前端 buildAssetTopology → HA 证据一致性`

入口：

```bash
python scripts/check_all.py --fast
```

此命令使用当前 Python 解释器执行后端门禁，并运行 Node 拓扑测试。缺依赖、测试失败、缺文件或零测试收集均返回非零；`--fast` 只省略前端生产构建，不省略发现验收。完整检查去掉 `--fast`。CI backend 同样执行该入口，并独立安装 Node 与前端静态检查依赖。

## 自动检查范围

| 范围 | 必须验证的用户结果 |
| --- | --- |
| MySQL / Oracle / PostgreSQL / SQL Server | 两节点成功链、重复识别幂等、正确端点/角色/方向、无新原生凭据；API 返回的数据直接输入真实前端拓扑函数 |
| 身份失败及未解析地址 | 不伪造地址、不显示健康、不保存观察型复制关系；保留原因 |
| MySQL 身份 | 已有地址和空 Host 候选都核对 UUID；UUID 缺失才采用 server_id；证据不足保留未验证 |
| 归属和作用域 | 未配置归属不造默认值；tenant/org 隔离；同私网地址及相同库标识不跨范围合并；全局旧 ID 保留 |
| SQL Server 方向 | 按可用性组的 DMV 主副本身份解析，不能根据角色列表猜箭头；多 AG 未选目标组时明确降级 |
| HA 一致性 | 缺关系、未知来源、手工关系、未验证端点、循环、多上游、跨范围关系不能支撑自动切换就绪；未采集为未知或警告，不伪报数据库故障 |
| RAC / MGR | 成员关系与主从复制分别验收；MGR 仅显示已保存的组成员关系，忽略残留主从箭头 |
| SSH | 自动发现新主机必须通过预存 known_hosts 校验；未知公钥或不匹配在发送密码前拒绝 |

完整四引擎链路用例见 `backend/tests/test_discovery_delivery_matrix.py`；作用域与身份见 `backend/tests/test_discovery_scope_integrity.py`；HA 完整性见 `backend/tests/test_ha_topology_completeness.py`。日常必跑清单在 `scripts/check_all.py`，门禁存在性及失败传播由 `backend/tests/test_check_all_script.py` 验证。
